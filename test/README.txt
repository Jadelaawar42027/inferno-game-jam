THE GORGING KITCHENS (Gluttony hub test level)

Install: drag this whole "test" folder into the root of the Godot project (next to project.godot).
Open res://test/gluttony_hub.tscn and press F6. Nothing in levels/ is touched.

It uses the project's own scenes: player, enemies, Teppan Oni, checkpoint, arena_trigger, floor_exit,
lore_text, wall_text, lantern_light, furnace_light.

Secret messages: SecretMessages/SecretMessage1..6 (lore_text instances). Edit the Text field on each.
